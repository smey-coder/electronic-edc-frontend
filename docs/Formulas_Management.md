នេះជាទិន្នន័យគំរូងាយៗ សម្រាប់បញ្ចូលតាមជំហាននៅទំព័រ Formula ចាប់ផ្តើមពីរូបមន្តងាយបំផុត (ច្បាប់អូម) ហើយរូបមន្តផ្សេងទៀតធ្វើដូចគ្នា។
#------------------------------------------------------------------------------------------------------------------
ជំហានទី ១៖ បង្កើតប្រភេទ (Category)

ចុច Manage categories រួចបញ្ចូល៖

ប្រអប់	តម្លៃ
Name	DC Circuits
Description	វ៉ុល ចរន្ត និងភាពធន់មូលដ្ឋាន

ចុច Save category ។ បើចង់បានមួយទៀត បន្ថែម AC Circuits ។

ជំហានទី ២៖ បង្កើតរូបមន្ត (Formula)

ចុច Create formula រួចបញ្ចូល៖

ប្រអប់	តម្លៃ
Title	Ohm's Law
Category	DC Circuits
Expression	I * R
Description	វ៉ុល = ចរន្ត × ភាពធន់
ជំហានទី ៣៖ បន្ថែមអថេរ (Variables)

នៅលើកាតរូបមន្ត ចុចរូបតំណាងបញ្ជី (Variables) រួចបន្ថែមម្តងមួយជួរ៖

Symbol	Display name	        Unit
I	    Current (ចរន្ត)	         A
R	    Resistance (ភាពធន់)	   Ω

បង្អួចនឹងស្នើ + I និង + R ពី Expression ដូច្នេះអ្នកអាចចុចជំនួសការវាយ Symbol ។

ជំហានទី ៤៖ សាកល្បងគណនា

ចុច Calculate លើកាត រួចបញ្ចូល៖

អថេរ	តម្លៃ
I	2
R	5

ចុច Compute ។ លទ្ធផលត្រូវតែជា 10 ហើយជំហានជំនួសតម្លៃគួរបង្ហាញដូច 2 * 5 = 10 ។

--------------------------------------------------------------------------------------------------------------------------

ចំណាំ៖

ទម្រង់ Expression: ខ្ញុំប្រើ * សម្រាប់គុណ និង ** សម្រាប់ស្វ័យគុណ។ បើ backend របស់អ្នកប្រើនិមិត្តសញ្ញាផ្សេង (ឧទាហរណ៍ ^ សម្រាប់ស្វ័យគុណ) សូមប្រាប់ខ្ញុំ ដើម្បីកែឧទាហរណ៍។
